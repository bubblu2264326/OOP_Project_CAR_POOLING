
# 🚗 CAR Pooling System (OOP Project in C++)

## 📝 Overview

The **CAR Pooling System** is a C++ application designed to facilitate carpooling among users. It allows users to share rides, reducing travel costs and environmental impact. This project is built using **Object-Oriented Programming (OOP)** concepts and incorporates **file handling** for data persistence.

---

## 🚀 Features

- ✅ **User Registration & Login**: Secure authentication for users and drivers.
- ✅ **Ride Sharing**: Users can offer or request rides.
- ✅ **File Handling**: Data is stored and retrieved using text files for persistence.
- ✅ **OOP Concepts**: Encapsulation, Inheritance, Polymorphism, and Abstraction are implemented.
- ✅ **Search Functionality**: Users can search for available rides based on location and time.
- ✅ **Ride Management**: Drivers can manage their rides, and users can book available rides.

---

## 🛠️ Tech Stack

- **Programming Language**: C++
- **OOP Concepts**: Encapsulation, Inheritance, Polymorphism, Abstraction
- **File Handling**: Text files for storing user and ride data
- **Data Structures**: Arrays, Classes for efficient data management

## 🧩 OOP Concepts Used

### 1. **Encapsulation**
- User, Driver, and Ride classes encapsulate their data and methods.
- Example: `User` class has private attributes like `username`, `password`, and public methods like `login()` and `register()`.

### 2. **Inheritance**
- The `Driver` class inherits from the `User` class, reusing common attributes and methods.

### 3. **Polymorphism**
- Overridden methods in derived classes (e.g., `Driver` class overrides `displayDetails()` from the `User` class).

### 4. **Abstraction**
- Abstract classes or interfaces (if used) define a clear structure for derived classes.
